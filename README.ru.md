# HeliLingo 2.5

**Выделите текст где угодно. Дважды нажмите Ctrl. Читайте перевод.**
Быстрый переводчик для Windows, который живёт в трее, показывает перевод по мере
поступления и может работать полностью офлайн.

Исходный код версии 2.0 удалён из репозитория, он остаётся в истории git.

## Возможности

- **Перевод на месте.** Выделите текст в любом приложении и дважды нажмите **Ctrl**.
  Рядом с выделением появится бабл. Он не забирает фокус, поэтому выделение
  сохраняется.
- **Потоковый вывод.** Текст появляется, пока движок ещё его пишет.
- **Быстрое окно** (**Ctrl+Shift+L**): печатаете — перевод следует за вводом.
- **Окно перевода** (**Ctrl+Alt+T**): полный текст, история, варианты.
- **Режим «Ультра»** (**Ctrl+Shift+S**): выделение на нескольких языках делится на
  фрагменты, каждый определяется и переводится отдельно.
- **Перевод с экрана и изображений** (**Ctrl+Shift+O** — область экрана): текст
  распознаётся встроенным OCR Windows или, по желанию, офлайн-моделью для изображений.
- **Заменить или скопировать.** Выделенный текст можно заменить переводом прямо в
  исходном приложении или просто скопировать перевод.
- **Словарные бабблы.** Значения слов по частям речи, варианты и краткая справка из
  Википедии.
- **Гибридная работа.** Несколько движков идут по очереди: первый, который выдал
  текст, побеждает; если он сломался на середине, подхватывает следующий.
- **Три темы** (синяя, тёмная, светлая, либо системная) и интерфейс на русском или
  английском. Шрифт Golos Text встроен в приложение.
- **Режим программиста.** В исходном коде переводятся только строковые литералы и
  комментарии; код остаётся байт в байт прежним.
- **Глоссарий** и **контекст**: предыдущие фрагменты помогают переводу оставаться
  согласованным.
- **Расширение для VS Code** (см. [VS Code](#расширение-для-vs-code)).
- **Приватность.** API-ключи хранятся в Диспетчере учётных данных Windows. История и
  статистика остаются на вашем ПК и могут быть выключены.

## Сервисы перевода

| Движок | Что нужно |
|---|---|
| Google | ничего (без ключа) или ключ Cloud |
| Yandex | ничего (без ключа) или ключ Yandex Cloud и id каталога |
| Bing | ничего (без ключа) или ключ Azure и регион |
| DeepL | ключ DeepL (Free или Pro) |
| OpenRouter | ключ OpenRouter и модель из списка |
| Офлайн-модели | однократная загрузка, см. ниже |

Офлайн-режим **включается по желанию**. Пока вы не включите офлайн-модели в
*Настройки → Офлайн и ускорение*, ничего локального не скачивается, не запускается и
не загружается; даже после включения модель скачивается только по кнопке **«Скачать»**.

## Офлайн-модели

| Модель | Что это | Загрузка | Работает на |
|---|---|---|---|
| OPUS-MT | en ⇄ ru, самая быстрая | ~157 МБ | CPU, CTranslate2 |
| Argos | пакеты en ⇄ ru | ~350 МБ | CPU, CTranslate2 |
| NLLB 600M / 1.3B | 200 языков (лицензия CC-BY-NC) | ~0,6 / ~1,3 ГБ | CPU или GPU, CTranslate2 |
| TranslateGemma 4B / 12B | перевод LLM с контекстом и глоссарием | 2,3 / 6,8 ГБ | CPU или GPU, llama.cpp |
| Granite Vision 4.1 | читает текст со скриншотов (обучена на английском) | 3,0 ГБ + среда | llama.cpp |

Модели привязаны к коммитам Hugging Face и проверяются по SHA-256. Загрузка после
обрыва продолжается с места остановки.

## Горячие клавиши

Значения по умолчанию; любую клавишу можно изменить в *Настройки → Горячие клавиши*.

| Действие | Клавиша |
|---|---|
| Перевести выделенное | дважды **Ctrl** |
| Быстрое окно | **Ctrl+Shift+L** |
| Окно перевода | **Ctrl+Alt+T** |
| Режим «Ультра» | **Ctrl+Shift+S** |
| Перевод области экрана | **Ctrl+Shift+O** |
| Скопировать перевод | **Ctrl+Shift+C** |
| Перевести и вставить вместо выделения | **Ctrl+Alt+R** |

Кнопки мыши 4 и 5 и сочетания с модификаторами тоже можно записать как клавиши.

## Расширение для VS Code

Расширение из папки [`vscode/`](vscode) обращается к запущенному приложению по
`127.0.0.1` с секретным ключом, который приложение записывает в
`%LOCALAPPDATA%\HeliLingo\api.json`. Оно переводит выделение или комментарий и строку
под курсором и может заменить выделение на месте. Локальный API приложения включён по
умолчанию; выключить его можно в *Настройки → Контекст и режимы*.

## Обновления

На странице «О программе» можно проверить последнюю версию по файлу `version.json`
в этом репозитории. Автоматическое обновление уже написано, но **выключено** в этой
версии; оно включится, когда появятся подписанные релизы.

## Сборка из исходников

Что нужно:

- Windows 10 или 11
- Rust (edition 2024) с инструментарием MSVC
- Node.js (для интерфейса на Svelte)
- CMake из Visual Studio Build Tools (нужен для `ct2rs`, привязки к CTranslate2).
  Если путь другой, поправьте его в [`.cargo/config.toml`](.cargo/config.toml).
- Держите путь сборки коротким: CMake падает на очень длинных путях.

```bash
cd ui && npm install && npm run check && npm run build && cd ..
cargo tauri build --no-bundle
```

Файл появится в `target/release/helilingo.exe`. Для проверок во время разработки
используйте `cargo check`. Ядро можно проверить без интерфейса, например:

```bash
cargo run -p hl-pipeline --example translate -- "Hello" ru
```

## Структура

```
crates/
  hl-core/       типы, гибридный маршрутизатор, запросы, разбиение текста и кода, промпты, глоссарий
  hl-cache/      кэш в памяти (moka) + дисковое хранилище (redb), история, статистика
  hl-detect/     определение языка (lingua, 10 языков) + правила по письменности
  hl-pipeline/   один перевод от начала до конца
  hl-providers/  Google, Yandex, DeepL, Bing, OpenRouter (потоковый), Википедия
  hl-offline/    каталог моделей, загрузки, рабочие процессы CTranslate2, llama-server, Granite
  hl-docs/       перевод файлов: DOCX / PPTX / XLSX / TXT / SRT
  hl-win/        хуки, захват через UI Automation и буфер, фокус, OCR, захват экрана
src-tauri/       приложение Tauri: команды, окна, трей, плагины
ui/              интерфейс на Svelte 5 + Vite + TypeScript
vscode/          расширение для VS Code
docs/            заметки о дизайне
```

Заметки для разработчиков — в [AGENTS.md](AGENTS.md), список задач — в [TODO.md](TODO.md).

## Приватность

- Запросы на перевод уходят только в выбранный вами движок (и в офлайн-модель на
  вашем ПК).
- Ключи хранятся в Диспетчере учётных данных Windows, а не в конфигурационных файлах.
- История и статистика хранятся локально и могут быть выключены.
